Artical

A, An, The. They precede the nouns and are used in undefined expressions.

A / an is used only with countable singular nouns. Those who start with the constant letter have "a" tag at the begginning of the word, and nouns that begin with a vowel that will have "an" tag at the beginning of the word. A / an is usually used when expressing what an object is. We cannot use coutable singular nouns alone.

Example

  • I saw an accident of a car.
  • That is an excellent pencil.
  • If we are talking about a specifec object, "the" is used. Countable singular or pular and can be used with all uncountable nouns.
  • If we are talking about an unknown object or person a / an, but if specified, "the" is used.

Examples

  • Yestarday, I bought a blouse and a a skirt. The blouse was surprisingly cheap, but the is usecd.
  • The movie is perfect.
