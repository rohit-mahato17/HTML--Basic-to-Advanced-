What is java?

Java is a high-level object-oriented programing language initially develope by sun- microsystems (Now owned by oracle corporation) it was designed to be platform-independent meaning that java virtual macine (jvm) installed. This platform independence is achieved this platform independence is achive through a "write once run anywere approach were code written in java can be compiled into bytecode that is then executed an any system compatibe JVM"
